# K. Nabidul Hasan Portfolio

This is a static HTML/CSS/JavaScript portfolio. The deployable entry point is the repository-root `index.html`; all linked images, project demos, C source files, certificates, and the current CV are included in this repository.

## Vercel

Import this repository in Vercel and use the repository root as the project root. Choose the `Other` framework preset, leave the build command empty, and leave the output directory at its default. Vercel will serve `index.html` and the accompanying static files directly.

## Run locally

From this directory, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/`.
